# 0009. 구성원 권한 체크 (#21)

- 날짜: 2026-11-09
- 상태: 목 구현 완료, 리뷰 통과(2차, affacf5) (스펙 rev 63). 실제 슬랙 확인은 #3 토큰 뒤.

## 결정

- 판정은 core 순수 함수 `permissionFor(members, slackId)` -> `guardian | child | unregistered`, `canWrite(permission)`(보호자만 true). role이 `guardian`이 아니면(누락·오타) child, 같은 slackId가 여러 구성원이면 가장 좁은 쪽(child). 파서(`wiki/format.ts`)가 이미 role을 child로 정규화하므로 같은 방향이고, 함수도 방어적으로 한 번 더 좁게 읽는다.
- 자리: ConnectHandler(연결 코드 DM) 뒤, Conversation 안에서 의도 추출 뒤 `change`/`choose` 분기 앞. 아이도 질문은 하므로 의도 추출은 그대로 한다. 거절하면 PendingStore에 요청을 만들지 않고 스레드에 안내만 답한다.
- **판정 시점은 두 번**: (1) 메시지 받을 때, (2) 버튼 넣기·다시 시도·고치기·고르기를 누를 때 위키를 다시 읽어 지금 권한으로. 그 사이 역할 변경·연결 해제를 막는다. 권한이 없으면 요청을 cancelled로 닫고 카드를 안내 문구로 바꾼다. 위키를 못 읽으면 쓰지 않는다(안전한 쪽). 단 읽기 실패는 권한 거절이 아니므로 요청을 닫지 않고 전이 전 상태(confirm·failed·choose)로 되돌린다: 원래 카드(버튼 포함)에 "위키를 읽지 못했어요. 잠시 뒤 다시 눌러 주세요."를 붙이고(고치기·고르기는 카드를 그대로 두고 본인에게만 알림), 잠시 뒤 다시 누르면 된다. 권한 거절만 cancelled이며 이미 넣은 게 있으면 "앞의 N개는 이미 넣었어요"를 붙인다. 넣기·다시 시도는 누르자마자 카드를 "넣는 중"으로 바꾼 뒤 판정하므로 판정 중 취소·중복 누름은 받지 않는다. 고치기는 판정 중 취소됐으면 카드를 덮어쓰지 않는다. 취소는 권한 없이 허용. 고치기로 보낸 글은 일반 메시지와 같은 판정을 탄다.
- **미등록 사용자의 질문은 허용**: 스펙은 쓰기만 제한한다. (오너 확인 항목: 가족 채널 밖 사람의 질문도 막을지)
- 문구: 아이 "아이 계정은 질문만 할 수 있어요. 일정이나 할 일을 넣고 싶으면 보호자에게 부탁해 주세요." / 미등록 "아직 가족 구성원으로 연결되지 않았어요. 대시보드 세팅의 연결 코드로 먼저 연결해 주세요."
