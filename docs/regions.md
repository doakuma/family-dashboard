# 지역 -> 기상청 코드 변환표 (`packages/core/src/regions.ts`)

/setup 1단계에서 사용자가 고른 지역을 `config.md`의 날씨 필드(`region`, `kmaNx`, `kmaNy`, `kmaMidLandRegId`, `kmaMidTaRegId`)로 바꾸는 정적 데이터다.
날씨 어댑터(#12)는 이 값만 읽는다.

## 범위

| 그룹 | 항목 | 단위 |
|---|---|---|
| 서울특별시 | 25개 자치구 전부 | 구 |
| 인천광역시 | 중·미추홀·연수·남동·부평·계양·서구, 강화군 (옹진군·동구 없음) | 구·군 |
| 경기도 | 주요 32개 시·군(수원·성남·성남 분당·고양·용인·부천·안산·안양·남양주·화성·평택·의정부·시흥·김포·광주·광명·군포·하남·오산·이천·안성·의왕·양주·파주·구리·과천·포천·동두천·여주·양평·가평·연천) | 시·군 (성남은 분당구만 따로) |
| 그 밖의 지역 | 없음 -> 1단계의 **"직접 입력"**(nx, ny, 육상 코드, 기온 코드, 지역 이름) | |

전국 표를 구하지 못해서(이 작업 환경에서는 기상청 사이트에 접근할 수 없었다) 서울·인천·경기 일부로 한정했다. 직접 입력 값의 허용 범위: nx 1~149, ny 1~253, 코드는 `11B00000` 꼴(숫자 2 + 대문자 1 + 숫자 5).

## 값의 의미

- `nx, ny`: 기상청 동네예보 격자 좌표. **시·군·구 대표 격자**라서 같은 구 안에서도 동에 따라 인접 격자와 1칸 차이가 날 수 있다(날씨 차이는 미미하다).
- `midLandRegId`: 중기예보 육상 예보구역. 서울·인천·경기는 모두 `11B00000`.
- `midTaRegId`: 중기예보 기온 예보 지점(도시 단위). 서울 구는 모두 `11B10101`, 인천은 `11B20201`, 경기는 도시별 코드.
  기온 지점 목록에 자기 이름이 없는 시·군(남양주·광주·군포·하남·의왕·구리·여주·양평)은 가까운 대표 도시의 코드를 썼고 `taApprox: true`로 표시했다(1단계에서 "가까운 도시 기준" 안내가 뜬다).

## 출처와 검증 상태 (중요)

- 출처: 기상청 동네예보 격자 좌표와 중기예보 구역 코드 체계를 구현자가 정리한 **초안**이다. 기상청 원본 표(격자 xlsx·중기예보 구역 코드표)와 **대조하지 않았다**. 서울 25구 격자와 서울·인천·경기 육상 `11B00000`은 공개 자료에서 흔히 쓰는 값이지만, 개별 항목은 리뷰어/오너가 원본과 대조해야 한다.
- 대조 전까지 이 표를 "검증 전"으로 본다. 틀린 값이 날씨 위치를 한두 격자 어긋나게 할 수는 있어도 앱이 깨지지는 않는다(형식·범위는 테스트가 확인한다).
- 테스트(`packages/core/src/wiki/setup.test.ts`): 키·이름 유일, 격자 범위, 코드 형식, 서울 25구 존재, 마포구 값이 예시 위키(`fixtures/sample-wiki/config.md`)와 일치.
- 고칠 때: `regions.ts`의 한 줄만 바꾸면 되고, `key`(예: `seoul-mapo`)는 바꾸지 않는다(화면 상태·저장된 입력이 이 키를 가리킨다). 지역을 늘릴 때도 같은 형식으로 줄을 추가한다.
